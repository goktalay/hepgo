Veritabanı işleri, olması gerektiği gibi

Bağlantılarınızı düzenleyin, sorgularınızı yazın, verinizi tek bakışta görün.

Altı veri kaynağı

PostgreSQL, Microsoft SQL Server, MySQL, MariaDB, SQLite ve DuckDB. DuckDB ile CSV, Parquet, JSON ve Excel dosyalarını doğrudan sorgulayın, tek sorguda birleştirin.

Bağlantı kartları

Renkli kartlar, sürükle-bırak klasörler, arama ve çoğaltma; tüm bağlantılarınız tek ekranda.

Şema gezgini

Sunucudan veritabanına, şemadan tablo, görünüm, fonksiyon, prosedür, trigger, indeks ve kolonlara; nesneler ihtiyaç anında yüklenir.

Tek tıkla veri

Tabloya çift tıklayın, ilk kayıtlar ızgarada; kolon gizleme, sıralama ve filtreler veriyi çeken SQL'e anında yansır.

SQL editörü

Sekmeler, Ctrl+Enter ile çalıştırma, otomatik tamamlama, çoklu sonuç, iptal ve sorgu geçmişi; tanımlar söz dizimi renkli.

Görsel sorgu oluşturucu

Tabloları tuvale sürükleyin, kolondan kolona JOIN çizin, kolon ve koşulları seçin; SQL canlı oluşur.

Hızlı ve akıcı

Büyük tablolarda sonuçlar parça parça gelir; milyonlarca satırda bile arayüz donmaz.

Dışa aktarma

Sonuçları CSV, TSV ya da JSON olarak kaydedin; yüz binlerce satır belleğe alınmadan doğrudan dosyaya.

Güvenli

Salt okunur mod varsayılan açık, değişiklik öncesi onay; parolalar Windows DPAPI'de, TLS ve SSH tüneli.

Web ile senkronizasyon

Bağlantılarınız, klasörleriniz ve ayarlarınız cihazlarınız arasında uçtan uca şifreli eşitlenir; sunucu içeriği okuyamaz.

Gece / gündüz

Koyu, açık ya da sistem teması; Türkçe ve İngilizce arayüz.

Tek Mastertool hesabı

Diğer Mastertool uygulamalarındaki hesabınızla girin; indirme, cihazlar ve destek mastertool.download'da.

Üç adımda başlayın

Kurulumdan ilk sorguya birkaç dakika.

Hesap oluşturun

E-postanızı doğrulayın; Hesabım sayfanızdaki size özel bağlantıdan SQL Master'ı indirip kurun. Mastertool hesabınız varsa aynı hesapla girin.

Bağlantı ekleyin

Veritabanı türünü seçin; sunucu, port, veritabanı ve kullanıcı bilgilerini girin.

Sorgulayın

Şemada gezinin, sorgunuzu yazın, sonuçları tabloda görün.

SQL Master'ı edinin

Hesap oluşturun, size özel bağlantıdan indirin. Bağlantılarınız cihazlarınız arasında uçtan uca şifreli eşitlenir.
